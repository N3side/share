## Стандарты беспроводной связи IEEE 802.11

Современные стандарты используют технологию **MIMO** (multiple input, multiple output) с несколькими антеннами для увеличения скорости и дальности.

| Стандарт           | Частота     | Описание и особенности                                          |
| ------------------ | ----------- | --------------------------------------------------------------- |
| 802.11             | 2,4 ГГц     | До 2 Мбит/с                                                     |
| 802.11a            | 5 ГГц       | До 54 Мбит/с                                                    |
| 802.11b            | 2,4 ГГц     | До 11 Мбит/с                                                    |
| 802.11g            | 2,4 ГГц     | До 54 Мбит/с. Обратная совместимость с 802.11b.                 |

#### Организации-регуляторы:

- **МСЭ (ITU)** (распределение частот), 
- **IEEE** (разработка стандартов), 
- **Wi-Fi Alliance** (сертификация совместимости устройств).
### Архитектура сети и Оборудование

- **Домашний маршрутизатор** объединяет 3 устройства: Точку доступа (AP), Коммутатор и Маршрутизатор

- Типы точек доступа:
    - **Автономные:** подходят для дома/малого офиса
    - **На основе контроллера (LAP):** Управляются централизованно через контроллер беспроводной локальной сети (**WLC**) по протоколу **LWAPP/CAPWAP**.

- Типы антенн:
    - **Всенаправленные:** Покрытие 360° (офисы, дома).
    - **Направленные:** Фокус сигнала в одну сторону (Yagi, параболические).
    - **MIMO:** Несколько антенн для увеличения пропускной способности.

### Топологии WLAN

- Ad hoc: соединение устройств p2p, т.е. без точки доступа
    
- Инфраструктурный режим:
    - **BSS (Basic Service Set):** Одна точка доступа, много клиентов. id - **BSSID** (MAC-адрес AP)
    - **ESS (Extended Service Set):** Объединение нескольких BSS через провода. Позволяет клиентам осуществлять бесшовный роуминг. id - **SSID**.

### Доступ к среде (CSMA/CA) и Ассоциация

WLAN работает в **полудуплексном** режиме. Для избежания коллизий используется метод **CSMA/CA**:

1. Клиент слушает эфир.
2. Отправляет запрос **RTS** (Ready to Send) на AP.
3. Получает разрешение **CTS** (Clear to Send) от AP.
4. Клиент передает данные и ждет подтверждения (ACK).
    

Процесс подключения клиента (3 этапа):

1. **Обнаружение AP:** Пассивное: AP рассылает Beacon-кадры (маяки) с SSID. Активное: Клиент рассылает Probe Request (запрос), AP отвечает Probe Response.
2. Аутентификация
3. Ассоциация (согласование параметров: SSID, пароль, режим сети, безопасность, канал).

### Протокол CAPWAP и WLC


**CAPWAP** — протокол для связи между легкими точками доступа (LAP) и контроллером (WLC).

Разделенная MAC-архитектура:
- WLC выполняет: аутентификацию, роуминг, маршрутизацию трафика.
- **Шифрование DTLS:** По умолчанию включено для управляющего трафика. Для трафика данных — настраивается опционально.
- **FlexConnect:**  для филиалов. Позволяет AP локально коммутировать трафик, если связь с центральным WLC прервана.

### Управление каналами и Планирование

- **2,4 ГГц:** Доступно 11-14 каналов (по 22 МГц). Чтобы соседние AP не мешали друг другу, используются неперекрывающиеся каналы: 1, 6 и 11.
- **5 ГГц:** Доступно 24 канала (по 20 МГц). Пересечений почти нет, что дает более быструю и стабильную работу в плотных сетях.


Правила развертывания:
- Избегать физических препятствий и источников помех
- Размещать AP высоко к центру скопления пользователей


### Угрозы WLAN

- **Перехват данных** решается шифрованием
- **Вторжение посторонних** решается строгой аутентификацией
- **DDoS-атаки** 
- **Вредоносные (Rogue) AP**. Точка доступа, подключенная к корпоративной сети без официального разрешения
- атака с перехватом (злой близнец). одинаковый ssid
