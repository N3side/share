## Firewall (Межсетевой экран)

Устройство защиты внутренней сети от внешних угроз.
### Типы межсетевых экранов
| Тип                 | Уровень OSI | Особенности                                     | Плюсы                                             | Минусы                                       |
| ------------------- | ----------- | ----------------------------------------------- | ------------------------------------------------- | -------------------------------------------- |
| **Пакетный фильтр** | L3, L4      | Фильтрация по IP и портам.                      | Быстрый, прост в настройке.                       | Уязвим для спуфинга; не проверяет фрагменты. |
| **Stateful (SPI)**  | L3, L4, L5  | Отслеживает состояние сессий (новые vs ответы). | Защита от DDoS и спуфинга; высокая эффективность. | Не видит Payload; сложности с UDP/ICMP.      |
| **Proxy (Шлюз)**    | L3-L7       |                                                 | Глубокая проверка данных.                         | Низкая скорость.                             |
**Дополнительно:**
 * **Хостовый:** ПО на конкретном ПК.
 * **Прозрачный (Transparent):** Фильтрация на L2 (мост).
## Cisco ASA
**Модельный ряд:**
 * **ASA 5505:** Малый бизнес (150 Мбит/с), работает как коммутатор.
 * **ASA 5506:** Средний бизнес (750 Мбит/с), работает как роутер.
 * **ASA 5515:** Enterprise/DCI (1-4 Гбит/с), высокая плотность портов и VPN.
**возможности:**
 1. **Виртуализация:** Разделение на независимые контексты.
 2. **Отказоустойчивость**
 3. Интеграция с Active Directory
### Зоны безопасности (Security Levels)
Трафик по умолчанию разрешен от **High → Low**.
 * **Inside:** Уровень **100** (максимальное доверие).
 * **Outside:** Уровень **0** (интернет).
 * **DMZ:** Промежуточный уровень для публичных серверов.
### Режимы работы и интерфейсы
 * **Маршрутизируемый):** Режим L3 (роутер). Поддерживает NAT, VPN, динамическую маршрутизацию.
 * **Transparent (Прозрачный):** Режим L2. Внедрение без изменения IP-адресации.
**Настройка интерфейса:** Требует имя (nameif) и уровень безопасности (security-level).
 * *Ограничение 5505:* Базовая лицензия — 2 полных VLAN + 1 ограниченный.
### Объекты и группы
 * **Network Object:** IP, подсеть или диапазон.
 * **Service Object:** Протоколы и порты.
 * **Object Groups:** Логическое объединение объектов для ACL и NAT
 
> Изменение IP в объекте автоматически обновляет все связанные правила.
### NAT и ACL
**Виды NAT:** Статический, Динамический, PAT, Policy NAT.
**Типы ACL:**
 * **Standard:** Для маршрутизации (OSPF).
 * **Extended:** Основной фильтр трафика.
 * **Ethertype:** Только для прозрачного режима (L2).
 * **Webtype:** Для настройки SSL VPN.
 * **IPv6:** Для соответствующего протокола.
