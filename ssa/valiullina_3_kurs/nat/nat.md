nat нужен чтобы преобразовать публичный ip в локальный. чтобы частные адреса могли повторяться в локальной сети нужен nat.

адреса которые могут быть только в локальной сети

| класс | диапазон внутренних адресов | префикс        |
| ----- | --------------------------- | -------------- |
|       | 10.0.0.0-10.255.255.255     | 10.0.0.0/8     |
| B     | 172.16.0.0-172.31.255.255   | 172.16.0.0/12  |
| C     | 192.168.0.0-192.168.255.255 | 192.168.0.0/16 |

nat настраивается на маршрутизаторе который находится на границе между локальной сетью и публичной

![[Pasted image 20251108120949.png]]

тупиковая сеть потому что у всех компьютеров и устройств только одна точка выхода в интернет и альтернативных путей у нее нет

внутренняя сеть это адреса устройств, преобразуемые технологией nat

![[Pasted image 20251108121141.png]]

адреса внешней сети это адреса назначения. 

локальные адреса это адреса которые появляются во внутренней части сети

статический nat это когда одно устройство в лок сети получает один уникальный публичный адрес

динамическое преобразование многие ко многим. но это хуйня если сеть загружена, потому что есть ограничения сколько устройств могут выходить

преобразование адреса и номера порта (PAT). многие к одному. т.е у одного адреса много устройств. Как отличить тогда устройства между собой? К каждому устройству будет назначаться порт по которому можно идентифицировать устройства. Везде исп-ся

Преимущества.

Безопасность. из глобальной сети адреса устройств из локальной сети не видно. максимум они могут увидеть публичный ip адрес

недостатки

Снижение производительности. нагрузка на устройство где настроен nat



Команды

### Статический nat



```
ip nat inside source static Конкретный частный адрес Конкретный публичный адрес
int gi 0/0
 ip nat inside 
int s 0/0/0
 ip nat outside

ip nat inside source static 192.168.1.10 40.40.40.10
int gi 0/0
 ip nat inside 
int s 0/0/0
 ip nat outside

```
### Динамический nat

```
access-list 1 permit {частная сеть} {обратная маска}
ip nat pool {название} {начало публичного адреса} {конец публичного адреса} netmask {Прямая маска}
ip nat inside source list 1 (Это acl пон да) pool {Название pool}

int gi 0/0
 ip nat inside 
int s 0/0/0
 ip nat outside

Пример

access-list 1 permit 192.168.1.0 0.0.0.255
ip nat pool PUBL 40.40.40.1 40.40.40.10 netmask 255.255.255.0
ip nat inside source list 1 (Это acl пон да) pool PUBL

int gi 0/0
 ip nat inside 
int s 0/0/0
 ip nat outside
```



### Nat с перегрузкой

```
access-list 1 permit {частная сеть} {обратная маска}
ip nat inside source list 1 int {название интерфейса} overload

int gi 0/0
 ip nat inside 
int s 0/0/0
 ip nat outside

Пример

access-list 1 permit 192.168.1.0 0.0.0.255
ip nat inside source list 1 int s 0/0/0 overload

int gi 0/0
 ip nat inside 
int s 0/0/0
 ip nat outside

```
