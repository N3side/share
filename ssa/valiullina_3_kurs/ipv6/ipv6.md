Типы ipv6 адресов

1. Одноадресная рассылка
2. Многоадресная
3. anycast. (отправляет на n устройств по индвидуальному адресу внутри 1 локальной сети)

ipv6 делится на 2 части.

1. префикс (сетевая часть) - 64 чит
2. узловая нахуй 64 бит

маска почти всегда 64. 

команды

```bash

ipv6 unicast-routing

int gi 0/0/0
ipv6 add 2001::1/64
ipv6 add FE80::1/64
ipv6 add FE80::1 link-local
no sh

```
