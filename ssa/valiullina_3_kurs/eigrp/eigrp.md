EIGRP может выполнять маршрутизацию для разных протоколов, включая IPv4 и IPv6.

Обнаружив новое соседнее устройство, маршрутизатор вносит запись, содержащую адрес и интерфейс соседнего устройства, в таблицу соседних устройств.

EIGRP был разработан как протокол маршрутизации, не привязанный к определенному уровню сети. В связи с этим EIGRP не может использовать сервисы UDP или TCP. Вместо них протокол EIGRP для доставки и приема своих пакетов использует надежный транспортный протокол (RTP).




Примечание. Аутентификация не обеспечивает шифрование обновлений маршрутизации EIGRP.

Пакеты подтверждений EIGRP

При использовании надежной доставки EIGRP передает пакеты подтверждений (ACK). Подтверждение EIGRP представляет собой пакет приветствия EIGRP без данных. RTP использует надежную доставку для передачи пакетов обновлений, запросов и ответов.

![[Pasted image 20251118000902.png]]

Для поиска сетей и выполнения других задач DUAL использует пакеты запросов и ответов. Для запросов и ответов используется надежная доставка. Для запросов может использоваться групповая рассылка или одноадресная передача, а ответы всегда передаются в виде одноадресных пакетов.\

```bash
network [сеть] [обратная маска]
passive interface [интерфейс]
auto-summary
```


Пример

```bash
router eigrp 100
 eigrp router-id 1.1.1.1
 network 192.168.1.0 0.0.0.255
 network 10.0.0.0 0.255.255.255
 passive-interface GigabitEthernet0/1
 auto-summary
```

Здесь:

- Сеть `192.168.1.0/24` — на интерфейсе `GigabitEthernet0/1`, например, локальная сеть с пользователями.
- Мы **не хотим**, чтобы EIGRP рассылал hello-пакеты в эту сеть.
- Поэтому делаем интерфейс **passive** — сеть всё равно участвует в EIGRP, но соседства там не будет.
