 метрика это приоритет выбора маршрута. чем ниже уровень, тем выше приоритет

### BGP

Протокол динамической маршрутизации, который соединяет разные автономные системы

А.С. - сеть одного провайдера
RIP,OSPF,EIGRP-протоколы внутр.маршрутизации, которые работают внутри одного провайдера

Виды BGP:
- Внешний (eBGP. адм расстояние=20) работает между разными A.C
- Внутри (iBGP. адм расстояние=200) работает внутри 1ой А.С, т.е он работает хуже внешнего

У BGP значение метрики=0 => он не умеет находить наикратчайшие пути

### Команды:

```
router bgp []
 neighbor [ip соседа BGP] remote-as [AS BGP соседа]
 network [адр.сети напрямую подключенных с соседом BGP] mask [mask]
```

### Проверка соседей

```
sh ip BGP
```

- Работает только в больших сетях, где много провайдеров
- Обновление BGP инкапсулируется с протоколом TCP, что гарантирует надежность передачи обновлений BGP

### Варианты настройки BGP

BGP может быть настроен вместе с маршрутом по умолчанию, но существуют свои плюсы и минусы этих настроек:

1) Разные AS соединяются только с помощью маршута по умолчанию. Это наименьшее эффективный способ отправки данных, т.к. устройства не всегда могут отправить пакеты через наикратчайшие пути
2) Маршрут по умолчанию + BGP - роутеры частично знают карту всей сети интернет, но в приоритете будет всегда маршрут по умолчанию, тем самым устройства не всегда могут найти наикратчайший путь
3) Только BGP - у всех роутеров есть карта сети интернет и как быстрее отправить данные до пункта назначения. Недостаток: все маршруты должны иметь большую память для хранения всех маршрутов

### Ретрансляция (3.5.5.5) на пограничном:

osfp<->bgp
```
router bgp
 redistribute ospf [AS ospf]
router ospf
 redistribute bgp [AS bgp] subnets
```

eigrp<->bgp
```
router bgp [as]
 redistribute [eigrp] [AS eigrp]
router eigrp [AS]
 redistribute bgp 65001 metric 1000 10 255 255 
```
