### Ретрансляция ospf - eigrp

Один и тот же марш если что
```

router ospf 1

```

ес что redistribute eigrp 1 metric 1 если ipv6

Причем один из процессов (osfp / eigrp), который соединяет процессы, должен иметь общую network



протокол динамической маршрутизации, основанный на технологиях отслеживания состояния канала и используется для нахождения кратчайшего пути алгоритмом Дейкстры для быстрого расчета наикратчайших путей

Две версии OSPF:
- v2lipv4
- v2lipv6

Характеристики: 

- бесклассовый протокол
- эффективность алгоритм SPF
- быстрая сходимость
- масштабируемость
- безопасность

У OSFPv2 аутентификация md5 и алгоритм безопасного хеширования
У OSPFv3 аутентификация IPsec

админ.дистанция - 110

Принцип работы:

- установка смежности - маршрутизаторы после включения OSFP маршрутизаторы отправляют Hello пакеты, идентифицируя устройство, у которого настроен OSPF.
- Маршрутизаторы обмениваются LSA-пакетами - о состоянии канала - пакет содержит инфу о напрямую подключенных сетях и стоимость каждого канала (стоимость - информация о полосе пропускания). Полоса пропускания обратно пропорциональна каналу стоимости).
- Создание таблицы топологии - каждый маршрутизатор после получения LSA пакета создает карту всей сети это один из недостатков OSPF
- Выполнение алгоритма кратчайшего пути (SPF) и добавление наикратчайших маршрутов в таблицу маршрутизации

Пути решения проблемы OSPF:

- Создание зон - после создании зон маршрутизаторы отправляют LSA-пакеты только внутри неё. 
- Основная зона - нулевая / магистральная , если изменения в одной зоне на работу других зон не влияет. маршрутизатор (ABR), который соединяет несколько зон OSPF с главной магистральной зоной Area 0, выполняя функции шлюза для трафика между этими зонами. он отправляет инфу о наикратчайших путях другим зонам.
- Создание внутри зон выделенного (DR) и резеврного (BDR) маршрутизатора. DR будет получать инфу об LSA-пакетах и запускает SPF для поиска путей, разгружая другие маршрутизаторы. При изменениях в топологии оповещают только DR-маршрутизаторы.
