Оборудование технологии MPLS  
  
mpLS - оборудование заказчика  
PE - граничный маршрутизатор оператора который удаляет или добавляет метки  
P - это внутренний маршрутизатор или магистральный, который коммутирует пакеты по меткам.  
  
Преимущества:  
  
- высокая производительность  
- быстрая коммутация  
- поддержка разных типов трафика:  
ipv4, ipv6, ethernet, atm, frame relay и т.д.  
  
Используется только операторами связи  
  
  
### VSAT  
  
это терминал с очень маленькой опературой. это технология построения частной сети WAN с использованием спутниковой связи. Применяемой в отдаленных местностях, ГДЕ НЕТ ДОСТУПА к кабельным провайдерам. ключевые моменты что нужно для этой технологии:  
  
- использует небольшую спутниковую антенну  
- обеспечивает связь удаленных офисов через спутник  
- маршрутизатор подключается к антенне, направленный на спутник оператора. сам спутник находится на геостационарной орбите. или по другому акватериальная. примерно 35000 км расстояние между спутниками  
  
  
### Цифровая абонентская линия или DSL  
  
это технология постоянного широкополосного доступа WAN, использующая обычные телефонные линии (витая пара). Клюевы характеристики:  
  
- обеспечивает постоянное ip соединение  
- модем DSL преобразует ethernet сигнал в DSL сигнал у провайдера используется точка присутсвия или по другому DSAM, который объединяет линии абонентов и мультиплексирует в высокоскоростной канал (временное разделение канала в TDM), засчет чего достигаются высокие скорости.  
  
Основные недостатки  
  
- ограничение по скорости  
- по расстоянию  
- зависит от длины линии до центрального офиса провайдера  
- чем дальше абонент, чем ниже скорость  
- ограничение инфраструктуры. используются медленные телефонные линии, которые могут быть устаревшими и некачественными.  
- Подключение через интернет провайдера (удаленный сотрудник не может напрямую подключиться к корпоративной сети. требуется vpn или аналогичная защита, что создает дополнительные сложности)  
  
итог он удобен, прост в использовании, но при удаленном подключении к сети надо использовать vpn  
  
### Кабельное подключение  
  
это технология доступа к глобальной сети через коаксиальные кабели кабельного тв. т.е до дома доходит кабельное тв и мы ставим дома модем который будет распределять трафик между чем хуй знает  
  
#### Характеристики  
  
- более высокая пропускная способность чем у DSL  
- используется кабельный модем, который преобразует цифровые сигналы для передачи по кабелю.  
- у оператора связи используется оконечная система линии кабельного модема CMTS. он также мультиплексирует данные от разных абонентов  
  
### Беспроводная сеть  
  
- wi-fi (802.11 стандарт)  
- wi-max (802.16 стандарт) это соединение беспроводное в глобальной сети, спутниковый интернет (он есть для частного использование у операатора и для публичного пользования)  
  
### Сотовая связь  
  
это технология беспроводной передачи данных и голоса через сеть сотовых базовых станций, покрывающих определенные зоны.  
  
Характеристики:  
  
- сеть состоит из базовых станций, которые находятся в центре ячейки и центрального контроллера, который управляет роумингом и отвечает за переключение абонента из одной зоны в другую (handover).  
  
Стандарты сотовой связи:  
- 2g (gsm это только голосовой трафик, SMS, пакетная передача данных, но скорость очень низкая при пакетной передачи)  
- 3g (передача видео, интернет и т.д. скорость 42 мбит/с)  
- 4g (lte до одного гбит/с)  
- 5g (не все оборудования используют его. 1 - 10 гбит / с)  
  
  
### VPN  
  
Виртуальная частная сеть это технология, которая позволяет создавать защищенное шифрованное соединение между двумя частными или между пользователем и корпоративной сетью через общедоступный интернет.  
  
Характеристики:  
  
- вместо выделенных линий vpn использует виртуальные туннели, который прокладываются через интернет. туннель обеспечивает конфидицальность и целостность данных  
  
Преимущества:  
  
- сокращение затрат  
- безопасность  
- масштабируемость (vpn можно везде использовать любой пользователь, совместим с широкополосными соединениями)  
  
Существует 2 типа доступа по vpn:  
  
1. Сеть vpn типа узел - узел (который мы будем настраивать. соединяет целые сети между собой)
2. сети vpn для удаленного доступа (предназначен для отдельных пользователей. отделььный пользователь - это сотрудник, клиенты, пользователь какой-то хзз хуйня вопрос. Каждый пользователь имеет клиентское по или использует веб-клиент. )
