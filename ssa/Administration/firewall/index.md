Firewall (стена безопасности) - устройство, которое защищает внутреннюю сеть от внешних сетей (интернет) и решает какой трафик пропускать, а какой нет. Изначально как отдельное устройство его не было, были acl для нас. 

### Типы межсетевых экранов

#### Межсетевой экран с фильтрацией пакетов
эти межсетевые экраны фильтруют трафик по пакетно, смотрит на ip адрес отпр, получ на порт и решает пропустить трафик или нет. 

Работает на сетевом уровне и на транспортном.

Преимущества:
- простой в настройке
- быстрый, почти не тормозит

Недостатки:
- можно обмануть с помощью ip-спуфинга
- Проблемы с фрагментными пакетами
- Часть фрагментов может пройти без проверки, т.к. относится к целому пакету. MTU по умолчанию (максимальный размер пакета, который может пройти через маршрутизатор, равен 1500 байт). и если проходит пакет размером 3000 байт, он делится на 2 фрагмента. 1 кусочек проверяется на наличие ip адреса отправителя и получателя, все последующие фрагменты - нет. 
- Сложные правила. нужно правильно уметь настраивать правила. 
- плохо работает с динамическими портами
- пакетные фильтры не сохраняют состояние, тем самым они проверяют каждый пакет по отдельности и не запоминает соединение

#### Межсетевой экран с отслеживанием или сохранением состояния 

По сравнению с первым он работает на сетевом, транспортном и на сеансовом уровне. В сравнении с первым это более умный фаервол, потому что он соединяет соединение, далее он понимает, что это новый запрос или ответ, и анализирует весь процесс общения. 

Плюсы:
- отслеживание состояние
- хорошая производительность, быстрее и эффективнее
- Есть защита от атак
- умеет распознавать ip-спуфинги, подозрительные подключения (DDOS атаки)
- ведет подробное логирование, может видеть что происходит в сети

Недостатки:
- не видит содержимое данных
- плохо работает с нескольким протоколами (UDP, ICMP)
- сложности с динамическими портами
- аутентификация не поддерживается (не понимает какой пользователь подключается)


#### Шлюз прикладного уровня прокси сервера
фильтрует трафик на основе следующих уровней: сетевой, транспортный, сеансовый, прикладной.
Это самый глубокий контроль, межсетевой экран работает как посредник, клиент с начала подключается к firewall'у, потом к серверу. Сервер не видит настоящего клиента. Firewall проверяет данные на основе приложений. 

Другие функции межсетевого экрана:
- **Межсетевой экран на основе хоста**. это приложение. которое надо установить на клиент. защищает только его. 
- **Прозрачный межсетевой экран**. Фильтрует сетевой трафик между парой интерфейсов, соединенных между собой через мост. 
- **Гибридный межсетевой экран**. Соединяет несколько типов межсетевых экранов, например firewall с сохранением состояния и firewall с прокс
### межсетевые экраны cisco asa, 
которые могут работать как firewall, который смотрит ip адреса, порты, соединения и также понимает какое именно используется, и что происходит внутри трафика. 

Функции:
- проверка трафика
- фильтрация трафика
- обнаружение атак
- логи
- оповещения


## Глава 9 Внедрение многофункционального устройства защита asa

ASA это аппаратное и виртуальное устройство для защиты сети. Существует несколько моделей:
- asa 5505. Работает в небольших и малых компаниях. Скорость до 150 мб в секунду. security plus это лицензия дополнительная, которую надо купить. похож на коммут
- asa 5506. Используется для среднего и крупного бизнеса. скорости передачи до  750 мбит в секунду. похож на роутер 
- asa 5515 для крупных компаний и датацентров. Скорость: 1-4 гбит в зависимости от модели. Макс пропускная способность, много интерфейсов, подходит для больших потоков данных и vpn. Расширенная функциональность межсетевого экрана. 
	1. Виртуализация. Один межсетевой экран можно разделить на несколько межсетевых устройств. Каждый контекст, как отдельный фаервол. Собственные правила. свои интерфейсы, свои администраторы. Физически одно устройство, но моежт работать, как несколько межсетевых устройств. 
	2. Высокая допустимость с высокой отказоустойчивостью. Два идентичных asa можно соединить в кластер (активный и пассивный кластер). 
	3. Межсетевой экран с идентификацией пользователя. может связать ip адреса с учетными зависимостями в active directory, тем самым правила доступа можно строить не по ip адресам, а по группам и по пользователям. 
	4. Сервисы контроля и сдерживания угроз. Обнаружение и блокировка атак, защита от вредоносного по и контента, и т.д. 

Asa работает и фильтрует трафик на основе зон:
- внутренняя зона (или сеть). Имя - inside. Это сеть, которая защищена и находится за сетевым экраном. уровень безопасности по умолчанию - 100. 
- Внешняя зона (или внешняя сеть). Это зона, которая находится за пределами защиты межсетевого экрана. Название интерфейса - outside. Уровень безопасности - 0.
- Демилитаризованная зона (DMZ). В этой зоне находятся веб-сервера компании, она разрешает пользователям из внутренних и внешних сетей доступ к защищенным сетевым ресурсам. 
	- Передача трафика из внутренней сети во внешнюю сеть разрешается. 
	- Из внутренней сети к DMZ зоне разрешается. 
	- Из внешней сети к DMZ зоне разрешается выборочно, 
	- внешней сети во внутреннюю сеть запрещается. Из DMZ зону во внутреннюю сеть тоже запрещается

### Режимы работы межсетевых экранов asa. 
- маршрутизируемый режим. asa работает к маршрутизатор третьего уровня. Интерфейсы разделяет раздные сети. , поддерживает nat vpn, динамическую маршутизаци.. и т.д, каждый интерфейс имеет свой ip адрес. применяет политику безопасности к проходящему трафику.

### ОБЬЕКТЫ И ГРУППЫ ОБЬЕКТОВ

Обьекты это именованная сущность которая хранит в себе какую то сетевую информацию,
например вместо того чтобы писать ip или порты им задается имя и используется в настройка
именно имя

### Преимущества:

Создается 1 обьект и этот обьект используется в правилах acl nat групповых обьектах и т.д.
любое изменение обьекта автоматически применяется ко всем правилам где они используются
Типы обьектов
Они бывают 2 видов: сетевой и сервисный

Сетевой обьект содержит ip, подсеть или диапазон ip
сетевой в основном используется в nat

```
object network (name)
host / subnet (ip)
	или
range 192.168.1.1 162.168.1.10
```

Сервисный обьект описывает протоколы и порты источника и назначения

```
object service (name)
service tcp destination eq ftp
```

также все сетевые сервисные обьекты можно обьеденить в группы, это позволяет создать логические наборы
которые в последствие используются в 1 правиле

```
object-group service SERVICES-1
service-object tcp destination ....

```

для настройки nat на asa сущетвует 4 вида nat:
1. статический
2. динамический
3. pat
4. nat на основе политик

комманды для настройки статического nat

```
object network SNAT
host 192.168.1.2
nat (inside, outside) static 8.8.8.1
```
