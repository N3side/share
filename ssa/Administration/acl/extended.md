acl это набор правил, разрешающий или запрещающий трафик. Созданное правило на маршрутизаторах присваивают на соответствующие интерфейсы в  зависимости от правила, которое формирует системный админ, интерфейсы могут быть исходящие или входящие.

С Acl используют шаблонную маску. Шаблонная маска это набор единиц, которые игнорируют биты в ip, набор нулей, которые совпадают со значением ip адреса. ACL в зависимости от протокола бывают ACL для ipv4 и ipv6

На один физ. интерфейс маршрутизатора можно максимально 4 правила настроить (ipv4 и ipv6 in/out). 

Виды acl:

- стандартный
- расширенный

Стандарт в правиле указывается отправитель поэтому он настраивается ближе к получателю. 
А в расширенном можно указать самого получателя. 


Стандартный acl в котором указывается ip адрес отправителя и поэтому контроля над получателем нет, поэтому стандартный acl настраивают ближе к получателю

Расширенный это список управления доступом, который фильтрует трафик на основе множества критериев:

- ip адрес отправителя / получателя
- протоколы (tcp/udp, icmp, ip)
- номера портов приложений (http, https, telnet, ssh, dhcp, ospf, и т.д., smtp)


Расширенные acl настраивают ближе к отправителю (к источнику). таким образом нежелательный трафик отклоняется близко к сети источника, не пересекая сеть интернет

Порты приложения (3 диапазона)

- Обще-известные зарезервированные порты (диапазон: 0-1023)
- Зарегистрированные порты для конкретных приложений 1024-49151
- Динамические порты (они автоматически назначаются на ваше устройство, которое ведет на интернет) 49152-65535.

Стандартный и расширенный acl могут настраиваться двумя способами:

Стандартные:

- 1–99 (стандартный)
- 1300–1999 (расширенный диапазон для стандартных)

Расширенные:

- 100–199 (расширенный)
- 2000–2699 (расширенный диапазон для расширенных)

Лучше использовать именнованный acl

- Нумерованный (стандартный используют диапазоны: 1-99) и (1300-1999) стандартный список контроля доступа IP
- (От 100 до 199) и (от 2000 до 2699): список контроля доступа расширенного протокола Ip

Лучше использовать именнованный acl
Именнованный список контроля доступа

Имя присваивается для определения списка контроля доступа

- Имено могу содержать

буквенно-цифроваые символы.
- Рекумоентуедтся у


access-list 114 permit tcp 192.168.10.0 0.0.0.255 any eq 22



established разрешает возврат в сеть 192.168.10.0/24 только того трафика, из какой сети он исходил. Без параметра established записи acl клиент может послать трафик на веб-сервер, но не получить обратный трафик, возвращающийся от веб-сервера

access list 103 permit tcp 192.168.10.0 0.0.0.255 any eq 80
access list 103 permit tcp 192.168.10.0 0.0.0.255 any eq 443
access-list 104 permit tcp any 192.168.10.0 0.0.0.255 established
