acl это правила которые настраиваются на маршрутизаторах, которые запрещают или разрешают. 

permit - разрешить
deny - запретить
remark - комментарий (ниче не делает)

Шаблонные маски

0 - означает совпадения значения с соответствующего бита в адресе
1 - означает игнорирует значения соответсвующего бита в адресе

Прямая маска 255.255.255.0
11111111.11111111.11111111.00000000
сетевая.узловая

Обратная маска 0.0.0.255
00000000.00000000.00000000.11111111
О и 1 исп-ся в маршрутизации


В протоколах динамической маршрутизации исп-ся обратные маски

Шаблонная маска 

0.0.1.127
00000000.00000000.0000000|1.01111111

все зависит от правила которые мы хотим применить



192.168.10.10
11000000.10101000.00001010.00001010
|00000000.00000000.0000000|1.|0|1111111

192.168.11.64
|11000000.10101000.0000101|1.|0|1000000

типа ему без разницы что находится где единицы. 0 или 1 по барабану. Главное чтобы в адресе совпало то что находится где нули. Если совпадает то трафик проходит иначе нет


Виды acl

Стандартные размещается ближе к получателю. Запрещает просто весь трафик для всех протоколов.

Нумерованные

access-list 1 permit [Сеть отправителя] [Шаблонная маска]
int интерфейс сеть отправителя
ip access-group in или out

Расширенные

ip access-list standart ИМЯ
permit Адрес сети отправителя Шаблонная маска

int Название интерфейса
ip access-group in или out


Расширенные размещаются ближе к отправителю. В расширенных можно написать кто кому конкретно запращает разрешает трафик. Может запрещать определнный протокол



сокращение написания acl

host  заменяет шаблонную маску 0.0.0.0 - рассматривается на совпадение

Наприме
access-list 1 permit 192.168.1.10 0.0.0.0
access-list 1 permit host 192.168.1.10

any заменяет шаблонную маску 255.255.255.255 игнорирует все биты 

Например
access-list 1 permit сеть 255.255.255.255
access-list 1 permit any
