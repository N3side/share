#### – Проверка пользователя:

- выполнить `whoami` → сохранить вывод в файл `whoami_result.txt`

#### – Исследование каталогов:

- выполнить `ls` (базовый, `-l`, `-a`, `-la`, `-l ~/Документы/Практическая_работа_3`);
- выполнить `ls -a ~/Документы/Практическая_работа_3 > Результаты/ls_result.txt`

#### – Перемещение по каталогам:

- выполнить `pwd` в текущем каталоге → сохранить путь в файл `cd_result.txt`;
- перейти в рабочий каталог → `pwd >> cd_result.txt`;
- перейти на уровень вверх (`cd ..`) → `pwd >> cd_result.txt`;
- вернуться в домашний каталог (`cd ~`) → `pwd >> cd_result.txt`

#### – Создание файлов:

- перейти в рабочий каталог;
- создать `file_new1.txt`, `file_new2.txt` и `file_new3.txt` командой `touch`;
- проверить создание `ls file_new*` → сохранить вывод в файл `touch_result.txt`

#### – Создание каталогов:

- создать `NewFolder` командой `mkdir`;
- создать вложенный `SubFolder` командой `mkdir -p`;
- перейти в `SubFolder` → сохранить `pwd >> mkdir_result.txt`

#### – Удаление файлов:

- создать `subfile1.txt` и `subfile2.txt` в `NewFolder/SubFolder`;
- перейти в рабочий каталог;
- сохранить вывод `tree` для `NewFolder` → `rm_result.txt`;
- удалить `subfile1.txt` командой `rm`;
- сохранить вывод `ls` для `NewFolder/SubFolder` → `rm_result.txt`

#### – Удаление пустого каталога:

- создать `NewFolder/SubFolder2`;
- сохранить вывод `tree` для `NewFolder` → `rmdir_result.txt`;
- удалить каталог командой `rmdir`;
- сохранить вывод `ls` для `NewFolder` → `rmdir_result.txt`

#### – Удаление непустого каталога:

- попытаться удалить `SubFolder` командой `rmdir` → ошибку перенаправить в файл `rm_r_result.txt`;
- удалить каталог командой `rm -r`;
- сохранить вывод `tree` для `NewFolder/` → `rm_r_result.txt`

#### – Переименование файлов:

- переименовать `file_new1.txt` в `file_renamed.txt` командой `mv`;
- сохранить вывод `ls file_*` → `mv_result.txt`

#### – Копирование и перемещение:

- скопировать `file_new2.txt` в `NewFolder/file_copy.txt` командой `cp`;
- переместить `file_new3.txt` в `NewFolder/file_moving.txt` командой `mv`;
- сохранить вывод `tree` (исключая *result.txt) → `cp_mv_result.txt`

#### – Просмотр содержимого файла:

- записать "Hello RedOS" в `file_renamed.txt` командой `echo`;
- просмотреть содержимое командой `cat` → сохранить вывод в `cat_result.txt`

#### – Изменение прав:

- изменить права `file` в рабочем каталоге (пользователю полные, группе добавить выполнение, остальным все запретить) командой `chmod`;
- проверить права командой `ls -l` или `stat`;
- запустить скрипт `./file` (результат запишется автоматически)

#### – Изменение группы владельца:

- изменить группу командой `chown :common file_renamed.txt`;
- проверить группу командой `stat` → сохранить вывод `stat -c %G` в `chown_result.txt`
